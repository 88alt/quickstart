# 首页色彩增强候选

2026-10-19，用户反馈当前设计色彩太淡、过于低调，希望更浓、更鲜艳、有生机。本提案只调整5180隔离原型，保留已确认的布局、形态、字号、间距、业务入口和系统菜单边界；属于新的色彩建议，尚非用户确认的正式主题。

## 三种对照

| 风格 | 方向 | 适用体验 |
| --- | --- | --- |
| 原版 classic | 已有低饱和蓝灰、浅图标 | 保留原设计作为相同数据和布局的对照 |
| 鲜明 vivid（推荐） | 宝石蓝强调、浓色蓝/青绿/紫图标、轻染色标题区域、浅蓝分段主操作 | 更有生机，同时保留长时间阅读的白色空间 |
| 浓彩 bold | 更浓的画布与选中面、实色蓝主操作、更强的图标渐变 | 视觉存在感更强，作为浓度上限候选 |

默认预览为鲜明版。根地址http://192.168.9.19:5180/，或在“设计预览→色彩风格”中切换。URL参数palette=classic/vivid/bold只用于设计比较，不写入首页配置。导航保留此评审参数。

## 色彩职责

正文使用深海军蓝/深色主题近白，辅助文字仍维持清晰对比；宝石蓝表达操作、选中与产品身份。蓝/青绿/紫的浓色图标增强工具辨认，白色图形在渐变最浅和最深端均需达到4.5:1。卡片使用小范围色晕与内描边增强结构，不改变边框宽度、尺寸或间距；文字阅读区仍以白/深色面板为主。

连接在线/离线、端口状态、服务运行与警示仍由业务决定。绿、琥珀及中性色保持各自状态语义；装饰蓝边不等于服务在线，选中服务不等于运行。图表内核、曲线采样、原有阈值不改；只沿现有令牌增强读数/图例。

分段主操作统一通过变量控制外框、底色及文字，菜单按钮跟随操作组；单独出现的摘要更多使用正常正文色，避免白字落到浅底。正文菜单恢复面板正常文字，不能继承白色主按钮文字。原业务组件设置按钮中明确的黑色单色路径在实验配色内跟随文字色，保留其他品牌/状态色和图形结构。

## 实施与检查

`design/homeColorStyles.css`承担候选令牌和视觉角色，`OrderedHome.vue`只增加URL派生风格和预览选项。原版使用已有令牌；`widgetActionGroup.css`与设计WidgetMenu增加带原值回退的操作颜色变量。没有正式首页导入、配置结构变更、布局算法或业务表单改动。

验收：三配色×中英×深浅×1440/1024/768/390/320，检查控件尺寸和文档与原版一致、左侧占位样式不变、正文/辅助/选中/状态/按钮/图标端点对比度≥4.5，配色选择不修改布局，应用库/菜单/编辑/摘要行为可用。继续采用[已确认外观规范](quickstart-home-widget-visual-standard.md)的布局与交互规则；本提案不把全站低饱和基线擅自改成已确认结论。
