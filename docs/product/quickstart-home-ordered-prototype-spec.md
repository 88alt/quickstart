# Quickstart R有序首页：当前原型规格

2026-10-15。用户选择R，并同意有限三列与单侧堆叠方案；本规格记录当前原型行为，不是最终视觉签字或正式开发完成。左侧系统菜单保持原样，独立预览只用不可操作宿主占位表示边界。

后续用户反馈：当前产品功能定义已认可，并要求先提交代码；编辑方式仍需明显优化。以下规则作为已认可的功能基线，具体编辑器呈现与交互继续设计，不将本次认可扩大为最终体验通过。

## 普通首页与结构

默认七模块：网络流量/连接60:40同排320px；应用整行152px；设备/系统65:35同排340px；磁盘/共享60:40同排330px。Docker/下载/远程可在模块清单开启。原NetworkFlow曲线、项目Vue/CSS和原创设备图标复用；没有顶部五入口或新增系统导航。

有序行→1～3分栏→卡片，固定深度。五模板：整行、两列、三列、左大右上下、镜像；后两者只有两分栏，其中一栏两卡。不支持继续横竖嵌套或自由坐标。外框同排等高，堆叠列的两卡加18px间距等于整列高度。卡片唯一出现，不把同一业务模块复制为另一套身份/状态。

模块最小宽度沿用注册表；固定行高受卡片最小高度约束，不由数据长度无限增长。连接/系统/共享/Docker/下载/远程在堆叠栏采用148px最小高度的专用紧凑摘要。标准图表/设备/磁盘/应用保留标准契约，不做CSS裁切来假装摘要。放不下时阻止修改并说明所需高度；由用户换卡、换模板或主动提高行高。上下60:40等比例同样受各卡最小高度限制，320px行通常只允许50:50。

布局比例针对扣除间距的实际右侧容器宽度，最小可读宽度优先于比例。多列按连续顺序拆行，不跨行补洞；两卡堆叠保持列内组合。低于650px的单列使用每张卡自身推荐高度并展开为标准内容；手机顺序始终按列优先，例如左A/B右C为A→B→C。DOM、键盘与视觉顺序一致，变宽恢复原结构和比例，响应式不会写回偏好。

## 编辑与恢复

“自定义首页”进入草稿。按行选择五种结构，调整行高、列宽预设/滑杆/分隔线、上下比例与分隔线；整行上/下移动，模块选择器用于放入、移位或交换；卡片拖动支持可视区域内交换，跨屏/触屏/键盘使用选择器替代。空槽位不在普通首页显示，可从编辑器重新填入。

减少模板槽位时，多余卡片移到后续新行；左右镜像保留原大卡/堆叠角色。隐藏卡片或收起行后从模块清单找回，开启隐藏模块独占新行。空布局仍保留添加、恢复和页脚应用/工具入口。普通态不画分栏外壳和布局边界；编辑态显示当前行、拖动手柄和落点强调。

取消恢复已应用布局；应用只更新浏览器内存，进入详情返回保留；撤销保留最近30步；恢复推荐在草稿内可撤销/取消。刷新恢复URL指定的示例（无preset为默认），不保存到账号、路由器或localStorage。编辑时详情导航提示先应用/取消，切换语言/布局示例须结束草稿；切换合成数据/主题可用于在草稿中检查降级。

## 应用、设备与降级

应用区为常用收藏、全部应用、系统工具和软件中心。常用最多6项，稳定ID在本次预览内保存；软件中心负责安装更新，状态详情卡可独立选择。受限卡片中系统工具打开原应用面板，不增加首页行高。页脚轻量工具入口保留原五快捷功能与八系统工具，全部模块隐藏也能找到。模块清单与应用面板的焦点循环、Escape与打开者焦点恢复可用。

设备名称、图标、品牌、在线数量与完整页来自同一合成库存和deviceId。在线不等于允许联网；缺限速服务不隐藏清单。首页只展示有界摘要，通过“查看全部”和单设备详情深入管理。固定地址/路线编辑权限继续依LAN DHCP分配权；外部分配时明确到分配地址的主路由操作，不按“旁路由”一词推断权限。

加载/空/失败/旧版/权限/旧快照、缺服务/未启用/异常/不支持、应用读取失败/空/大量、长设备名和24磁盘可通过顶部设计预览切换。磁盘摘要最多4块，保留总数及完整清单入口；设备摘要按卡片真实宽高确定，不新增无限列表或统计。

## 预览与架构边界

公开入口5180，顶部“设计预览”可切换默认、左大右上下、镜像、三列服务示例，以及主题、语言、数据场景与DHCP分配方。preset只用于合成设计示例，不是已发布的模板偏好接口；旧R/G/F比较留作历史，不再重新请求选型。

单一共享读取协调器，排序不改变可见模块集合则不重建读取任务；网络状态30秒、库存/端口/系统30秒、磁盘/服务/版本60秒，原图独立5秒、协调器跳过traffic。隐藏/卸载清理，诊断请求日志最多120项；布局撤销最多30快照。布局不写策略、不启动后台扫描。此处为原型浏览器行为，真实API/持久化/冲突/迁移、路由器资源预算及IPK/APK留给后续正式阶段。

实际验收与截图见 `docs/evidence/m66/row-layout/10-interactions/`、`11-review/`。M66.12须用户实际审阅默认、模板、编辑与手机界面后确认，自动化和此规格不能代替美感验收。
